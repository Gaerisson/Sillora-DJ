# Contribuer à Sillora DJ

## Signaler un bug

Indiquer la version, Windows et le périphérique de sortie, puis les étapes et le résultat attendu. Pour un problème audio, préciser le style, la durée du passage, les BPM, les corrections de grille et l’état du sidechain. Un extrait dont le partage est autorisé facilite la comparaison.

Ne joindre ni jeton Remote, ni identifiant de compte, ni musique privée, ni profil complet. Les chemins personnels peuvent être masqués dans les journaux.

## Proposer un changement

1. Décrire le comportement concret dans une issue ou une pull request.
2. Garder une modification centrée sur un problème.
3. Lancer `npm test` ; pour une interface, joindre une capture sombre et une capture claire.
4. Pour du DSP, fournir un rendu comparatif et préciser le signal, les crêtes, les limites et les conditions de test.

Une mesure de continuité ou de niveau ne prouve pas à elle seule une qualité musicale. Distinguer le comportement vérifié des préférences d’écoute.

Les dépendances conservent les conditions décrites dans [THIRD_PARTY.md](THIRD_PARTY.md).
